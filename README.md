# The Ritzy Heirloom

One-page website for The Ritzy Heirloom, an antique shop in Neptune Beach, Florida.

The name on the page is the shop wordmark (`public/logo.jpg`). The gold rule and frame use `#b07c28`, sampled from that wordmark.

## Run locally

```bash
npm install
npm run dev
```

The development server listens on port 4721 at [http://localhost:4721](http://localhost:4721).

## Production

```bash
npm run build
npm start
```

`npm start` serves the built site on port 4721.
