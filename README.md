# The Ritzy Heirloom

One-page website for The Ritzy Heirloom, a boutique antique shop in Neptune Beach, Florida. The page uses the shop wordmark and describes what the shop carries: antiques and vintage finds, vintage jewelry, fine art, European and English pieces, antique French fabrics and wallpapers, and one-of-a-kind treasures.

The name on the page is the shop wordmark (`public/logo.jpg`). The gold rule and frame use `#b07c28`, sampled from that wordmark.

## Run locally

```bash
npm install
npm run dev
```

The development server listens on port 4721 at [http://localhost:4721](http://localhost:4721).

## Production

```bash
npm run build
```

`npm run build` writes a static site to `out/`. GitHub Pages publishes `main` from this repository at [https://damienstarkey978.github.io/TheRitzyHeirloom/](https://damienstarkey978.github.io/TheRitzyHeirloom/).
